# Rock Paper Scissors Game

A browser-based implementation of the classic Rock Paper Scissors game, built as part of [The Odin Project Foundations Course](https://www.theodinproject.com/lessons/foundations-rock-paper-scissors).

## Features

- Interactive UI styled with clean CSS and custom card layouts.
- Play against a computer opponent with randomized choices.
- Live-updating score tracker for both the player and the computer.
- 5-round game loop with automatic resetting and end-game score tracking.

## Built With

- **HTML5** for structure
- **CSS3** for styling and layout
- **JavaScript** for game logic and DOM manipulation

## How to Play

1. Clone or download the repository.
2. Open `index.html` in your web browser.
3. Click on **Rock**, **Paper**, or **Scissors** to make your choice against the computer.
4. Play through the 5-round match to see who wins!
